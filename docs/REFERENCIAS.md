# Referencias y ampliaciones

## Referencias en formato APA

Cotton, R. (2013). *Learning R: A step-by-step function guide to data analysis*. O’Reilly Media.

Ihaka, R., & Gentleman, R. (1996). R: A language for data analysis and graphics. *Journal of Computational and Graphical Statistics, 5*(3), 299–314. `https://doi.org/10.1080/10618600.1996.10474713`

## Recursos de acceso libre

[Lecturas y ejemplos por lección](materiales_adicionales.html).

- [R para ciencia de datos · español](https://es.r4ds.hadley.nz/): Libro de consulta: importar, transformar, visualizar y comunicar.

- [dplyr](https://dplyr.tidyverse.org/reference/): filter, select, mutate, arrange, group_by, summarise y joins.

- [tidyr](https://tidyr.tidyverse.org/articles/pivot.html): Tablas ordenadas; pivot_longer y pivot_wider.

- [ggplot2](https://ggplot2.tidyverse.org/): Gramática de gráficos y referencia de geometrías.

- [readr](https://readr.tidyverse.org/): Importación de CSV y tipos de columnas.

- [stringr](https://stringr.tidyverse.org/): Limpiar y buscar texto.

- [lubridate](https://lubridate.tidyverse.org/): Interpretar y agrupar fechas.

- [R Markdown](https://rmarkdown.rstudio.com/lesson-2.html): Informes que integran texto, código y resultados.

- [Tidyverse](https://www.tidyverse.org/): Ecosistema de paquetes para ciencia de datos.

- [readxl](https://readxl.tidyverse.org/): Ampliación: importar archivos Excel.

- [janitor](https://sfirke.github.io/janitor/): Ampliación: nombres de columnas y tablas de frecuencias.

- [forcats](https://forcats.tidyverse.org/): Ampliación: ordenar categorías.

- [Posit · hojas de referencia](https://posit.co/resources/cheatsheets/): Resúmenes para usar después de practicar.

- [R · descarga](https://cran.r-project.org/): Instalar el motor de R.

- [RStudio Desktop](https://docs.posit.co/ide/user/download.html): Editor recomendado; R se instala por separado.
